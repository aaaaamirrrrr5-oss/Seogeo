# Site Manager — اپ اندروید (نسخه 5.1.0)

این بسته فقط **اپ اندروید (Capacitor)** است؛ افزونهٔ وردپرس جداگانه تحویل شده (`site-manager-bridge-5.1.0.zip`).

## ساخت APK
1. محتویات این پوشه را در ریشهٔ یک مخزن GitHub بارگذاری کنید (پوشهٔ `.github` باید در ریشه باشد).
2. از Actions گردش‌کار «ساخت APK اپ Site Manager» را اجرا کنید.
3. خروجی در Artifact با نام `site-manager-app-...` است (`app-debug.apk`). برای APK/AAB امضاشده چهار Secret (`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`) را تعریف کنید.

## اتصال
افزونهٔ Site Manager Bridge **نسخهٔ 5.1.0** را نصب و فعال کنید؛ بدون آن، کارت «خلاصهٔ هوشمند سایت» و اتصال چت به اطلاعات سایت کار نمی‌کند.

## تازه‌ها در 5.1.0
کارت سلامت سایت، قالب‌های آمادهٔ پرسش، سؤال پیشنهادی بعد از هر پاسخ، کنترل «اتصال به اطلاعات سایت» و نمایش اینکه چه داده‌ای ماسک/استفاده شد. جزئیات: `CHANGELOG-fa.md`.

> APK در این محیط ساخته/روی گوشی آزموده نشده (Android SDK نبود)؛ ساخت با GitHub Actions انجام می‌شود.
