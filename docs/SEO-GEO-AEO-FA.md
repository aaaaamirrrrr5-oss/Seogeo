# راهنمای مرکز هوشمند SEO / GEO / AEO — Site Manager 4.9.3

## امکانات افزوده‌شده

### SEO
- بررسی عنوان صفحه و طول تقریبی آن.
- بررسی وجود توضیحات متا از فیلدهای Beano، Rank Math و Yoast.
- شمارش H1 و استخراج ساختار heading.
- شناسایی تصویرهای بدون alt.
- تخمین حجم متن قابل مشاهده برای شناسایی صفحات بسیار کم‌محتوا.
- بررسی دسترسی robots.txt و نقشه سایت WordPress.

### GEO
- بررسی نشانه‌های JSON-LD در محتوای قابل دسترس وردپرس.
- بررسی وجود فایل اختیاری llms.txt.
- ارائه پیشنهادهای ساختاری برای روشن‌کردن موجودیت‌ها، منابع و اطلاعات قابل استناد.

### AEO
- شناسایی نشانه‌های FAQ و فهرست‌ها.
- بررسی وجود زیرعنوان‌های کافی برای ساختاردهی پاسخ‌ها.
- پیشنهاد پاسخ مستقیم و ساختار پرسش‌محور.

## هوش مصنوعی محلی بدون API پولی
- اتصال اختیاری به Ollama روی `http://127.0.0.1:11434`.
- نام مدل از تنظیمات خوانده می‌شود و در کد ثابت نیست.
- endpoint چت: `POST /wp-json/smb/v3/ai/chat` با `provider: "ollama"`.
- نمونه نصب مدل روی سرور: `ollama pull qwen2.5:7b`.
- Ollama باید توسط مدیر سرور نصب و اجرا شود. افزونه مدل را دانلود یا سرویس را مدیریت نمی‌کند.
- اتصال loopback محدود شده تا URL دلخواه یا مقصد شبکه‌ای به مسیر SSRF تبدیل نشود.

## API ممیزی
`POST /wp-json/smb/v3/ai/seo-audit`

بدنه:
```json
{"limit":30}
```
نیازمند کلید Bridge متصل به کاربر دارای `manage_options` است. خروجی شامل `scores`, `counts`, `pages`, `issues`, `checks`, `limitations` است.

## نکات مهم و محدودیت‌ها
- امتیازها heuristic و داخلی‌اند؛ امتیاز Google، رتبه SERP یا شاخص رسمی نیستند.
- GEO فقط با بررسی HTML قابل اثبات نیست. سنجش واقعی به پایش نتایج و citation در موتورهای مولد نیاز دارد.
- این نسخه به Google Search Console، Bing Webmaster Tools، داده بک‌لینک، Core Web Vitals یا Lighthouse متصل نشده است.
- تحلیل صفحه‌ها فقط روی صفحات عمومی منتشرشده همان وردپرس انجام می‌شود؛ این endpoint خزنده عمومی برای هر URL دلخواه نیست.
- داده ساختاریافته‌ای که توسط قالب یا افزونه در زمان رندر به head اضافه می‌شود ممکن است در محتوای ذخیره‌شده پست دیده نشود؛ بنابراین تشخیص JSON-LD یک نشانه اولیه است نه حکم قطعی.
- هیچ تغییری در قالب یا محتوای سایت اعمال نمی‌شود. گزارش فقط خواندنی است.
- مدل محلی به منابع اینترنتی خودکار دسترسی ندارد؛ جستجوی وب فقط در صورت فعال بودن ابزار رسمی ارائه‌دهنده ابری قابل استفاده است.
