## خزنده‌های هوش مصنوعی
خزنده‌ها در سه گروه بررسی می‌شوند: **جستجو** (OAI-SearchBot، Claude-SearchBot، PerplexityBot)، **درخواست مستقیم کاربر** (ChatGPT-User، Claude-User، Perplexity-User) و **آموزش مدل** (GPTBot، ClaudeBot، Google-Extended، Applebot-Extended، CCBot، Bytespider).
فقط مسدودبودن گروه جستجو/کاربر امتیاز سایت را کم می‌کند. مسدودکردن گروه آموزش یک تصمیم سیاستی مشروع است و جریمه نمی‌شود. فهرست نام‌ها ممکن است در طول زمان تغییر کند و باید با مستندات رسمی هر شرکت تطبیق داده شود.

## JSON-LD
Organization، WebSite، Article (نوشته) یا WebPage (برگه)، BreadcrumbList و FAQPage. FAQPage فقط از تیترهای پرسشی‌ای ساخته می‌شود که همراه پاسخ، واقعاً در متن صفحه دیده می‌شوند و حداقل دو جفت لازم است.
- اگر Yoast SEO، Rank Math، AIOSEO، SEOPress، The SEO Framework یا Slim SEO فعال باشد، تولید Schema کنار می‌رود. قالب یا آداپتور Beano می‌تواند با فیلتر `smb3_geo_schema_owner` مالکیت Schema را اعلام کند.
- محصولات ووکامرس و صفحات رمزدار یا noindex دست‌نخورده می‌مانند.
- پیش از فعال‌سازی، پیش‌نمایش Schema در اپ یا endpoint `/ai/geo-preview` قابل مشاهده است.

## llms.txt
فقط محتوای منتشرشده، بدون رمز و غیر noindex فهرست می‌شود. فایل واقعی `llms.txt` روی هاست همیشه بر نسخه مجازی اولویت دارد. **تأثیر llms.txt بر خزنده‌های اصلی تأیید‌شده نیست؛** هزینه فعال‌سازی کم است، اما نتیجه تضمین نمی‌شود.

## API
| مسیر | متد | scope کلید |
|---|---|---|
| `/ai/geo-report` | GET | `ai_geo_view` |
| `/ai/geo-run` | POST `{limit}` | `ai_geo_manage` |
| `/ai/geo-settings` | GET / POST | `ai_geo_view` / `ai_geo_manage` |
| `/ai/geo-preview?kind=llms` یا `kind=schema&post_id=` | GET | `ai_geo_view` |

همه مسیرها علاوه بر scope، دسترسی `manage_options` وردپرس را نیز لازم دارند.

## آنچه این موتور انجام نمی‌دهد
- متن، عنوان، alt، لینک، قیمت یا موجودی را تغییر نمی‌دهد و چیزی را منتشر یا حذف نمی‌کند.
- استناد واقعی ChatGPT، Gemini، Claude یا Perplexity، رتبه، Search Console و Core Web Vitals را اندازه‌گیری نمی‌کند.
- امتیازها شاخص داخلی برای اولویت‌بندی‌اند، نه امتیاز رسمی هیچ موتوری.
