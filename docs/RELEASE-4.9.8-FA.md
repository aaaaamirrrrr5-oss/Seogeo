# گزارش انتشار Site Manager 4.9.8

## تغییرات
- ممیزی محتوایی عمیق‌تر برای مقاله، برگه، محصول و انواع عمومی سفارشی
- بررسی خلاصه وردپرس، هدینگ‌ها، تازگی محتوا، لینک داخلی/خارجی
- تحلیل تکرار عنوان و توضیح متا در بین صفحات اسکن‌شده
- بررسی هم‌پوشانی موضوعی احتمالی با برچسب هشدار heuristic
- فرصت‌های لینک داخلی دارای مبدأ، مقصد، واژه مشترک و anchor پیشنهادی
- بررسی توضیحات خالی دسته‌ها و برچسب‌ها
- تحلیل پایه کاتالوگ WooCommerce
- برنامه اقدام ۷، ۳۰ و ۹۰ روزه در گزارش وردپرس و اپ
- نسخه اپ و افزونه هماهنگ: 4.9.8

## تست‌های انجام‌شده
- `npm run check:js`: موفق
- `npm test`: موفق
- `bash bridge/site-manager-bridge/scripts/check.sh`: موفق
- `php -l` روی فایل‌های PHP افزونه از طریق check.sh: موفق
- تست‌های PHP static/contract: موفق؛ از جمله 16 بررسی خوداصلاح‌گر
- تست‌های JS مربوط به گزارش جدید: موفق؛ از جمله کنترل نمایش محصول، لینک داخلی و action plan

محیط اجرای تست PHP: PHP 8.4.24. این اجرا ادعای تست روی تمام نسخه‌های پشتیبانی‌شده PHP را ندارد.

## تست‌نشده
- نصب و اجرای افزونه روی سایت زنده کاربر
- بررسی خروجی واقعی در قالب Beano Coffee
- اتصال Google Search Console، GA4 یا Bing Webmaster Tools
- اجرای Ollama/مدل محلی
- اندازه‌گیری واقعی citation در ChatGPT، Gemini یا دیگر موتورهای مولد
- ساخت APK و تست دستگاه واقعی Android در این نوبت
- اجرای کامل تست مرورگر در دستگاه Android واقعی

## امنیت و مرز خودکارسازی
- ماژول جدید فقط داده‌های داخل وردپرس را می‌خواند و پیشنهاد تولید می‌کند.
- لینک داخلی، اصلاح متن، alt، عنوان، category و taxonomy به شکل خودکار تغییر نمی‌کنند.
- قیمت، موجودی، سفارش، مشتری، قالب و فایل‌های پوسته تغییر نمی‌کنند.
- اصلاح خودکار قبلی محدود به پر کردن متای توضیحات خالی از متن موجود و قابل بازگشت باقی مانده است.

## توجه به امتیازها
امتیازهای SEO/GEO/AEO شاخص داخلی برای نظم‌دهی مشکلات هستند. رتبه گوگل، حجم جستجو، ترافیک، بک‌لینک یا citation واقعی از این امتیازها قابل استنتاج نیست.
- `npm run test:all` تا مرحله آزمون DOM اجرا شد اما در این محیط به دلیل نصب نبودن بسته توسعه‌ای `jsdom` متوقف شد (`Cannot find module 'jsdom'`). بخش‌های `check:js` و `npm test` پیش از آن کامل و موفق بودند. آزمون DOM/مرورگر را موفق اعلام نمی‌کنیم.
