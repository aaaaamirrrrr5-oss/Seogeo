# مرکز SEO · GEO · AEO در وردپرس — نسخه 4.9.5

## مناسب برای چه محیطی؟
این ماژول داخل افزونه Site Manager Bridge اجرا می‌شود و به VPS، Node.js، Ollama یا API Key نیاز اجباری ندارد. از PHP و داده‌های خود WordPress استفاده می‌کند. روی هاست اشتراکی معمولی نیز قابل اجراست، مشروط به نسخه PHP و محدودیت‌های میزبان.

## امکانات فعال
- اسکن حداکثر ۱۵۰ محتوای منتشرشده اخیر از نوع نوشته، برگه و محصول ووکامرس (در صورت فعال بودن).
- دریافت HTML صفحه عمومی همان سایت با `wp_safe_remote_get` برای بررسی خروجی واقعی، در صورت امکان سرور.
- بررسی عنوان، meta description، H1، واژه‌شمار، تصاویر فاقد alt، لینک داخلی، canonical و JSON-LD.
- بررسی مقدماتی FAQ و تیترهای پرسشی برای AEO.
- بررسی سیگنال‌های نویسنده، تاریخ، منبع و داده ساختاریافته برای GEO.
- پیشنهاد توضیحات متا به شکل پیش‌نویس قاعده‌محور.
- ذخیره توضیحات متا فقط پس از تأیید مدیر.
- اسکن هفتگی WP-Cron و گزارش آخرین اسکن.

## نصب
1. از سایت نسخه پشتیبان بگیرید.
2. افزونه قبلی Site Manager Bridge را از مسیر افزونه‌ها غیرفعال نکنید؛ ZIP جدید را به‌عنوان به‌روزرسانی نصب کنید. در صورت نمایش پیام جایگزینی، تأیید کنید.
3. در پیشخوان، Site Manager → SEO · GEO · AEO را باز کنید.
4. «اجرای ممیزی کامل سایت» را بزنید.
5. پیشنهادها را بازبینی کنید؛ برای ذخیره هر توضیح متا، دکمه همان ردیف را جداگانه بزنید.

## سازگاری با افزونه‌های سئو
اگر Yoast SEO، Rank Math یا AIOSEO برای همان نوشته توضیحات متا داشته باشند، ماژول توضیح متای آن افزونه را دست‌کاری یا جایگزین نمی‌کند. توضیح متای Site Manager فقط زمانی در head چاپ می‌شود که متای افزونه‌های یادشده برای آن نوشته خالی باشد.

## محدودیت‌های صریح
- این موتور، تحلیل قاعده‌محور است؛ مدل زبانی تولیدکننده متن نیست.
- «امتیاز ۸۰» رتبه گوگل یا امتیاز رسمی SEO نیست.
- پایش رتبه کلمات، Search Console، backlink index و Core Web Vitals به اتصال منابع اختصاصی/ابزارهای اندازه‌گیری نیاز دارد.
- تشخیص استناد در ChatGPT، Gemini و سایر موتورهای مولد از داخل سایت به‌تنهایی ممکن نیست؛ نیازمند آزمون بیرونی و دوره‌ای است.
- WP-Cron به بازدید سایت وابسته است؛ برای زمان‌بندی دقیق، cron واقعی هاست بهتر است.
- بررسی HTML فرانت‌اند در صورت محدودیت loopback یا firewall ممکن است انجام نشود؛ گزارش همچنان با داده ذخیره‌شده محتوا ادامه پیدا می‌کند.

## حریم خصوصی
در اسکن SEO این ماژول، محتوای صفحات به API خارجی فرستاده نمی‌شود. واکشی HTML فقط به آدرس همان سایت انجام می‌شود. تغییرات محتوایی فقط با مجوز و nonce وردپرس انجام می‌شود.
