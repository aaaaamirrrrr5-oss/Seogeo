# گزارش توسعه نسخه 4.9.4 — DeepSeek و حالت خودکار بدون API

## تغییرات پیاده‌سازی‌شده
- افزودن ارائه‌دهنده اختیاری DeepSeek Cloud از مسیر رسمی `https://api.deepseek.com/chat/completions`.
- ذخیره کلید DeepSeek با رمزنگاری AES-256-GCM، مشابه سایر کلیدهای ارائه‌دهنده‌ها.
- افزودن حالت «خودکار امن» در اپ؛ این حالت فقط Ollama محلی را فراخوانی می‌کند و هرگز بی‌اجازه به OpenAI، Claude یا DeepSeek Cloud fallback نمی‌کند.
- افزودن گزینه DeepSeek Cloud در انتخاب‌گر مدل اپ و پیام شفاف درباره نیاز به کلید API.
- افزودن جستجوی عمومی محدود و رایگان Google News RSS (حداکثر ۸ نتیجه) برای حالت‌های Auto/Ollama/DeepSeek، بدون API Key جستجو؛ منابع به مدل به‌عنوان داده غیرقابل‌اعتماد تزریق و در پاسخ بازگردانده می‌شوند.
- مستندسازی اجرای مدل `deepseek-r1:7b` از طریق Ollama بدون API Key.
- ارتقای شماره نسخه اپ، افزونه و package به 4.9.4.
- حفظ قالب سایت و عدم افزودن مسیر ویرایش فایل‌های پوسته.

## محدودیت‌هایی که صادقانه باقی می‌مانند
- RSS رایگان فقط اخبار/فیدهای عمومی را جستجو می‌کند و جایگزین جستجوی کامل وب، Google Search Console یا رتبه‌سنجی نیست.
- DeepSeek Cloud بدون کلید API رسمی قابل فراخوانی تضمین‌شده نیست. رایگان بودن یا دسترسی وب‌سایت DeepSeek به معنی API رایگان برای برنامه ثالث نیست.
- اجرای DeepSeek بدون API در این نسخه از طریق Ollama روی VPS/سرور انجام می‌شود؛ مدل به‌صورت بومی داخل APK اندروید اجرا نمی‌شود.
- اجرای زنده Ollama، DeepSeek Cloud و نصب روی یک WordPress واقعی در این محیط انجام نشده است.
- APK در این محیط ساخته نشده؛ GitHub Actions برای ساخت APK Debug در مخزن فراهم است، اما build واقعی GitHub در این نوبت اجرا نشده است.
- پایش واقعی رتبه Google، داده Search Console، Core Web Vitals، بک‌لینک و شمارش citation در ChatGPT/Gemini/Bing همچنان نیازمند اتصال حساب‌ها/منابع معتبر و اجرای زمان‌بندی‌شده است؛ امتیازهای heuristic فعلی نباید به‌عنوان رتبه یا citation واقعی تعبیر شوند.
- سیستم چندعاملی کامل با چرخه وظایف مستقل و خزنده عمومی مستقل هنوز تکمیل نشده است.

## راه‌اندازی DeepSeek بدون API
1. روی VPS دارای منابع کافی Ollama نصب کنید.
2. دستور `ollama pull deepseek-r1:7b` را اجرا کنید.
3. در پیشخوان وردپرس → Site Manager → هوش مصنوعی، نشانی loopback و نام مدل را ثبت کنید.
4. در اپ گزینه «خودکار امن» یا «Ollama محلی» را انتخاب کنید.
5. اگر به DeepSeek Cloud نیاز دارید، کلید API رسمی را جداگانه در تنظیمات وارد کنید و آن را دستی انتخاب کنید.
