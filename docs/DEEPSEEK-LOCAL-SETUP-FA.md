# راه‌اندازی DeepSeek رایگان و محلی

## روش بدون API Key
DeepSeek-R1 را به‌صورت مدل محلی با Ollama اجرا کنید. نمونه:

```bash
ollama pull deepseek-r1:7b
ollama serve
```

در تنظیمات Site Manager:
- Ollama URL: `http://127.0.0.1:11434`
- Model: `deepseek-r1:7b`

سپس در اپ «خودکار امن» یا «Ollama محلی» را انتخاب کنید. حالت خودکار فقط مدل محلی را اجرا می‌کند و به‌هیچ‌وجه بی‌اجازه به API ابری نمی‌رود.

## مدل ابری اختیاری
گزینه DeepSeek Cloud از API رسمی استفاده می‌کند و به کلید API رسمی نیاز دارد. کلید در تنظیمات افزونه ذخیره و رمزنگاری می‌شود. اگر کلید ندارید، این گزینه را انتخاب نکنید.

## نکته سرور
در این نسخه Ollama باید روی همان سرور WordPress یا loopback قابل دسترس باشد. اجرای Ollama روی هاست اشتراکی معمولاً ممکن نیست. در صورت نصب Ollama روی VPS جدا، معماری اتصال امن شبکه‌ای باید جداگانه طراحی شود؛ آدرس عمومی Ollama را در این نسخه وارد نکنید، زیرا افزونه عمداً فقط loopback را قبول می‌کند.

## تحقیق اینترنتی رایگان با RSS
هنگام فعال بودن گزینه تحقیق، حالت‌های Auto/Ollama/DeepSeek می‌توانند از Google News RSS عمومی تا ۸ نتیجه مرتبط دریافت کنند. این مسیر API Key جستجو نمی‌خواهد، نتایج و تاریخ/پیوند منبع را به مدل می‌دهد و منابع را در پاسخ نمایش می‌دهد. RSS فقط کشف خبر و منابع عمومی است؛ جایگزین جستجوی کامل وب، Google Search Console یا سنجش رتبه نیست.
