# عامل اجرای دستور هوشمند — 4.9.6

## هدف
تبدیل دستور متنی مدیر وردپرس به برنامه تغییرات قابل مشاهده و قابل تأیید برای نوشته، برگه و محصول ووکامرس.

## گردش کار
1. مدیر نوع هدف و عبارت جستجو را مشخص می‌کند؛ برای ایجاد محتوا نوع «ساخت پیش‌نویس» را انتخاب می‌کند.
2. دستور فارسی/انگلیسی به مدل انتخاب‌شده داده می‌شود. `auto` فقط Ollama محلی را فراخوانی می‌کند و به ابر fallback پنهانی ندارد.
3. سرور حداکثر پنج محتوای قابل ویرایش را پیدا و زمینه محدود آن‌ها را در اختیار مدل قرار می‌دهد.
4. خروجی مدل فقط به JSON مشخص با عملیات allowlist تبدیل می‌شود. شناسه هدف‌ها باید با محتوای بازیابی‌شده تطابق داشته باشد.
5. پیش‌نمایش به اپ برمی‌گردد؛ هنوز تغییری ذخیره نشده است.
6. مدیر هر اقدام را انتخاب و صریحاً تأیید می‌کند.
7. سرور مجوز و اثر انگشت محتوا را دوباره بررسی می‌کند. اگر محتوا از زمان ساخت پیش‌نمایش تغییر کرده باشد، همان اقدام رد می‌شود.
8. برای محتوای موجود، عنوان/متن/خلاصه و SEO metadata در همان آیتم ذخیره می‌شود. برای محتوای جدید، وضعیت draft اجباری است.

## دامنه مجاز
- بازنویسی عنوان، متن و خلاصه مقاله یا برگه.
- بازنویسی نام، توضیح کامل، توضیح کوتاه و متادیتای SEO محصول ووکامرس.
- تنظیم عنوان SEO، توضیح متا و focus keyword از طریق adapter متای داخلی/Yoast/Rank Math.
- ساخت مقاله، برگه یا محصول جدید به شکل پیش‌نویس.

## خارج از دامنه
- انتشار مستقیم آیتم جدید؛ حذف محتوا؛ تغییر قیمت، موجودی، SKU، ویژگی‌ها، سفارش، بازپرداخت، مشتری؛ تغییر تنظیمات، افزونه، پوسته، کد یا فایل قالب.
- ساخت backlink، ارسال ایمیل/درخواست همکاری یا تماس با سایت دیگر.
- اجرای انبوه روی کل سایت در یک درخواست. سقف هر برنامه ۵ هدف است و برای دسته‌های بزرگ باید چند batch کنترل‌شده اجرا شود.

## امنیت
- فقط کاربر دارای `manage_options` می‌تواند planner/apply را اجرا کند.
- action scope مستقل `ai_command_manage` به سیستم محدودیت کلید اضافه شده است.
- برنامه با transient کوتاه‌عمر ۳۰ دقیقه‌ای، متصل به user و همان home_url نگهداری می‌شود.
- متن ورودی سایت untrusted محسوب می‌شود و در پیام سیستم به مدل دستور داده شده از prompt injection پیروی نکند.
- `wp_kses_post`، sanitization و check capability هنگام apply انجام می‌شود.
- برای محتوای موجود، WordPress revision پیش از تغییر درخواست می‌شود.
- اجرای apply فقط با `confirmed=true` و انتخاب indexهای معتبر پذیرفته می‌شود.

## راه‌اندازی
- از حالت `auto` یا `ollama` برای اجرای بدون API Key استفاده کنید؛ Ollama باید روی همان میزبان و loopback قابل دسترس باشد.
- DeepSeek Cloud/OpenAI/Claude فقط در صورت وارد کردن کلید رسمی در پیشخوان قابل انتخاب هستند و ممکن است هزینه داشته باشند.
- برای استفاده از عامل: اپ → دستیار هوشمند → دستوردهنده و مجری هوشمند سایت.

## محدودیت‌های فعلی
- اجرای واقعی روی سایت مشتری یا محیط staging در این نوبت انجام نشده است.
- خروجی مدل ممکن است نادرست باشد؛ مدیر باید متن، ادعاها، منابع، محصول و لینک‌ها را قبل از تأیید بازبینی کند.
- RSS خبری منبع تحقیق کامل وب، keyword volume یا backlink index نیست.
- قابلیت rollback اختصاصی برای command planner در UI فعلاً وجود ندارد؛ از revision وردپرس و backup کامل سایت استفاده کنید.
- تولید متن با مدل محلی به RAM/CPU و کیفیت مدل نصب‌شده بستگی دارد. در میزبان اشتراکی ممکن است Ollama قابل اجرا نباشد.

برای انتخاب یک batch از محصولات یا مقالات اخیر، در عبارت هدف `*` بنویسید. این مقدار فقط پنج محتوای اخیر از نوع انتخاب‌شده را به پیش‌نمایش می‌آورد؛ به‌روزرسانی تمام سایت یک‌باره انجام نمی‌شود. پیش‌نمایش وضعیت فعلی و متن پیشنهادی را کنار هم نشان می‌دهد.
