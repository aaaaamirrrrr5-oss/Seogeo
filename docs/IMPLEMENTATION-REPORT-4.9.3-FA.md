## مواردی که در این محیط تست زنده نشدند
- APK ساخته نشد؛ این محیط Android SDK/پروژه Gradle تولیدشده را در اختیار نداشت. Workflow مخزن برای ساخت APK Debug با GitHub Actions حفظ شده است.
- نصب زنده روی یک سایت WordPress واقعی و اجرای REST endpoint روی هاست واقعی انجام نشده است.
- اجرای Ollama و تولید پاسخ با یک مدل واقعی تست نشده است؛ باید Ollama روی همان سرور یا loopback در دسترس باشد.
- سنجش رتبه واقعی گوگل، Core Web Vitals، Search Console، بک‌لینک‌ها و اندازه‌گیری citation در ChatGPT/Gemini/Bing انجام نشده است.

## محدودیت معنایی مهم
امتیازهای SEO/GEO/AEO در این نسخه heuristic و برای اولویت‌بندی داخلی هستند؛ رتبه موتور جستجو یا میزان استناد هوش مصنوعی را نشان نمی‌دهند. برای GEO واقعی باید پایش جداگانه نتایج و citation موتورهای مولد، در بازه‌های زمانی و با ثبت شواهد اضافه شود. همچنین موتور چندعاملی کامل و خزنده عمومی مستقل برای هر URL هنوز پیاده‌سازی نشده است.

## راه‌اندازی
1. فایل ZIP افزونه را در WordPress از مسیر افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه نصب کنید.
2. در پیشخوان Site Manager ← هوش مصنوعی، URL محلی Ollama و نام مدل نصب‌شده را تنظیم کنید.
3. برای استفاده از Ollama، سرویس را روی سرور اجرا و مدل را از منبع رسمی نصب کنید؛ نمونه: `ollama pull qwen2.5:7b`.
4. نسخه کامل سورس را در مخزن GitHub اپ بارگذاری و workflow را به‌صورت دستی اجرا کنید؛ خروجی APK Debug در Actions Artifacts قرار می‌گیرد.
