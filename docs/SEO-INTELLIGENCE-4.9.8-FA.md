# قابلیت‌های تکمیلی SEO Intelligence در Site Manager 4.9.8

## قابلیت‌های جدید

### ۱. ممیزی عمیق‌تر هر محتوا
- طول محتوا و شمارش واژه‌ها
- شمارش H1 و ساختار هدینگ‌ها
- تشخیص پرش در سلسله‌مراتب هدینگ‌ها
- تصاویر بدون alt یا alt خالی (نیازمند تشخیص تزئینی/معنادار بودن تصویر توسط مدیر)
- شمارش لینک داخلی و خارجی
- وجود خلاصه وردپرس
- نبود یا تکراری بودن متای توضیحات
- بازبینی محتوای قدیمی‌تر از ۱۸ ماه؛ این هشدار به معنای نادرست بودن محتوا نیست

### ۲. ممیزی ووکامرس
برای محصولاتی که WooCommerce فعال است، موارد زیر بررسی می‌شوند:
- توضیحات کوتاه محصول
- توضیحات اصلی محصول
- تصویر شاخص و تعداد تصاویر گالری
- دسته‌بندی محصول
- تعداد ویژگی‌های ثبت‌شده و نوع محصول

این ماژول قیمت، تخفیف، مالیات، موجودی، SKU، سفارش یا مشتری را تغییر نمی‌دهد.

### ۳. تحلیل بین‌صفحه‌ای
- گروه‌بندی عنوان‌های دقیقاً تکراری
- گروه‌بندی توضیحات متای دقیقاً تکراری
- تشخیص هم‌پوشانی احتمالی موضوعی براساس مجموعه واژگان
- پیشنهاد صفحات مقصد برای لینک‌سازی داخلی
- نمایش URL مبدأ و مقصد، واژه‌های مشترک و انکر پیشنهادی

**محدودیت:** هم‌پوشانی واژگانی اثبات Keyword Cannibalization نیست. تشخیص قطعی به Search Console، قصد جستجو و تحلیل انسانی نیاز دارد. فرصت لینک داخلی نیز فقط پیشنهاد است و لینک را خودکار اضافه نمی‌کند.

### ۴. ممیزی طبقه‌بندی‌ها
- دسته و برچسب مقاله
- دسته و برچسب محصول (در صورت فعال بودن WooCommerce)
- فهرست توضیحات خالی و راهنمای تکمیل

توضیحات دسته‌ها خودکار تولید یا ذخیره نمی‌شوند.

### ۵. برنامه اقدام
گزارش شامل موارد زیر است:
- برنامه اولویت‌بندی‌شده برای ۷ روز آینده
- فهرست اقدامات ۳۰ روزه
- نقشه راه ۹۰ روزه
- اثر/اولویت به‌صورت راهنما، نه پیش‌بینی قطعی رتبه

## استفاده
1. افزونه Site Manager Bridge 4.9.8 را نصب یا به‌روزرسانی کنید.
2. اپ را به سایت متصل کنید.
3. در اپ وارد مرکز SEO / GEO / AEO شوید.
4. «ممیزی کامل + اصلاح خودکار امن» را اجرا کنید؛ مجوز اصلاح متای خالی در همان صفحه قابل کنترل است.
5. گزارش شامل امتیازهای داخلی، مشکلات، تحلیل محصولات، لینک‌های داخلی پیشنهادی، صفحات هم‌پوشان، ایده‌های محتوا و برنامه ۷/۳۰/۹۰ روزه خواهد بود.

## آنچه خودکار تغییر نمی‌کند
- متن مقاله یا صفحه
- عنوان H1، عنوان صفحه یا نامک
- alt تصاویر
- لینک‌های داخلی یا خارجی
- قیمت، موجودی، SKU، تخفیف و سفارش
- دسته‌بندی و توضیحات taxonomy
- قالب/پوسته یا فایل‌های Beano Coffee
- انتشار عمومی محتوا

اصلاح خودکار موجود در این نسخه فقط متای توضیحات خالی را از متن یا خلاصه موجود همان محتوا می‌سازد و امکان rollback دارد.

## نیازهای داده برای تحلیل پیشرفته‌تر
برای رتبه، کلیک، impression، conversion و query واقعی باید Search Console و Analytics به‌صورت مستقل و مجاز متصل شوند. برای اندازه‌گیری واقعی سرعت و Core Web Vitals باید PageSpeed/CrUX یا منبع واقعی داشته باشید. داده‌های استناد GEO/AEO به اندازه‌گیری جداگانه موتورهای پاسخ نیاز دارند. در نبود این منابع، برنامه فقط معیارهای داخلی سایت را نمایش می‌دهد.
